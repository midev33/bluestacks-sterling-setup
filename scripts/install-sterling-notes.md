# Sterling Book & Go — Play Store notes

These notes are for the Android app used by Sterling Sport & Wellness / Sterling Book & Go.

## Find and install the app

1. Start the intended BlueStacks 5 Android instance.
2. Open **Google Play Store** and sign in only with an authorized Google account.
3. Search for **Sterling Book & Go**.
4. Confirm the app name and publisher shown by Google Play before installing.
5. If needed for identification, the expected Android package hint is:

   `com.s24.bookandgo`

   A package hint is not a substitute for verifying the Play Store listing. Do not download an APK from an unofficial mirror.
6. Install or update the app from Google Play and open it once to confirm that it launches.

## Credential boundary

**STOP before login.** This repository contains no Sterling username, password, PIN, recovery code, API key, or token. Obtain credentials from the captain through the approved channel and enter them interactively only when explicitly authorized. Never add credentials to a script, issue, commit, screenshot, or log.

## Useful troubleshooting details

When reporting an installation problem, capture only non-sensitive details: Windows version, BlueStacks version, Android instance type, app version, package hint, and the visible error text. Redact account names, email addresses, passwords, and tokens.
